# 参考串口工具设计规格（pic/2.png 深度像素分析）

> 来源：`pic/2.png`（浅色主题）、`pic/5.png`（深色主题，同工具）、`pic/1.png`（次要参考）。
> 方法：PIL 像素级扫描（分区边界、颜色统计、控件几何测量）。
> 用途：xcom_lua ImGui 仪表盘重设计的目标规格。

## 1. 窗口总体结构（2.png，1662×1218）

```
┌──────────────────────────────────────────────────────────────┐
│ 标题栏+工具条 y0-60   浅蓝白 #F0F3FA，深色线性图标 #13161D     │
│   (x28-58 浅蓝芯片 #DAE6FE = 活动状态按钮)                     │
├──────────────────────────────────────────────────────────────┤
│ 左工具面板 x0-548          │ 20px 间隙 │ 右数据区 x568-1654    │
│  (串口配置+大绿SEND)       │ 1px 灰线  │  (接收 log + 发送区)   │
│                           │ x=549/566 │                      │
└──────────────────────────────────────────────────────────────┘
```

- 顶栏高 60px，一体化（无独立标题栏）
- 左右面板间隙 ~20px，内有**两条线**：x=549 深灰 `#8A8889`、x=566 浅灰 `#EBE9EA`
- **左右面板背景色相同** `#F8F9FD`，靠间隙分隔，不用硬边框

## 2. 配色总表

### 2.1 表面

| 区域 | 颜色 | 说明 |
|---|---|---|
| 窗口/面板底 | `#F8F9FD` | 带一丝蓝的白 |
| 顶栏工具条 | `#F0F3FA` | 略深，区分于内容 |
| 接收 log 背景 | `#F9F9FB` | 中性白（与面板底仅微差） |
| **发送编辑器背景** | **`#F8F8F0`** | **黄调白！发送区特有** |
| 左栏下半部（扩展工具） | `#FDF9F6`~`#FCF8F5` | 暖调白 |
| 输入框/组合框 | `#FFFFFF` 白 + 边框 `#D5D8DF` |
| 选中行高亮 | `#333438`（深色主题）/浅色为整行浅灰蓝 | 无边框 |

## 3. 左工具面板布局（对应咱们的右侧栏）

```
y=162  [标签]  [组合框 x322-538]     ┐
y=228  [标签]  [组合框 x322-538]     │ 5 行串口参数
y=288  [标签]  [组合框 x322-538]     │ 行距 60-66px
y=348  [标签]  [组合框 x322-538]     │
y=414  [标签]  [组合框 x322-538]     ┘
y=504  [标签]  [输入框 x322-424]      附加字段
y=518-579  ██████ 绿色大 SEND ██████  525×61，圆角 8px
y=590+  ───── 1px 分隔线 ─────
y=590+  扩展工具区（暖白底），区块间 1px 线分隔
```

**对齐规则**：
- 标签列右对齐到 x~310，值列统一左边缘 x=322
- SEND 按钮通栏宽（左右各 14px 边距），高 61px
- 复选框在标签左侧（x15-53 列）

## 4. 右数据区布局（对应咱们的左主区）

```

             行首橙 [时间戳]，正文黑，TX 红
```

## 5. 控件样式规范

| 控件 | 规格 |
|---|---|
| 主按钮（SEND） | 绿 `#008000`，圆角 8px，白字小号居中，宽=容器-28px，高 61px |
| 普通按钮 | 白底 `#FFFFFF` + 1px 边框 `#D5D8DF`，圆角 ~4px |
| 活动芯片 | 浅蓝 `#DAE6FE` 填充，圆角 |
| 组合框/输入框 | 白底，1px 边框 `#D5D8DF`，圆角 ~4px，高 ~32px |
| 复选框 | 13-16px 方框，1px 深边框；选中=灰填充 `#C3C2C7` |
| 图标 | 线性描边风格，深色 `#13161D`，1.5-2px 线宽，约 24×24 |
| 行高亮 | 整行底色变化，无边框无圆角 |

## 6. 映射到 xcom_lua（左右镜像）

| 参考图元素 | xcom 对应 | 改动 |
|---|---|---|
| 左栏串口参数 5 组合框 | 右侧栏 SERIAL PROFILE | 对齐到统一栅格（标签右对齐+值列左对齐） |
| 绿色大 SEND | 发送区主按钮 | **Send 改为绿色 `#008000` 大按钮** |
| 发送编辑器黄调白 `#F8F8F0` | 发送区背景 | 发送工作台底色 |
| log 区橙时间戳 `#FF7C24` | 时间戳着色 | `#B36B00` → **`#FF7C24`**（或加深保可读性的折中） |
| TX 红色数据 `#F04C4D` | （新功能）发送回显 | 发送的文本以红色回显到 log |
| 双线面板分隔 | 主区与侧栏间 | 侧栏去硬边框，改 1px 浅线 |
| 线性图标 | IconButton | 保持现有矢量绘制风格，统一 1.8px 线宽 |
| 活动芯片 `#DAE6FE` | 页签/开关 | Toggle ON 色可参考 |

## 8. 与 1.png 的关系

1.png 是该工具的文档页：白 `#FEFEFE` + 灰卡 `#EEEEF0` + 淡绿白 `#F9FEFA` 的
配色是其**品牌色的柔和版**。仪表盘主参考 2.png/5.png；1.png 用于侧栏淡绿白
`#F9FEFA` 这类柔和底色的选择。
